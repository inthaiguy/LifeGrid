# Open questions

## Product
- Name. "Life Grid" is a placeholder.
- Is the grid for one person only, or can it hold tabs for family members (as the source sheet does)?
- How should travel-heavy months be coloured — by home base only, or can a cell show a second "was away in" colour?
- What counts as done? 100% filled, or is "nothing memorable" a valid answer that closes a cell?

## Storage and sharing
- Is an optional account ever wanted, or does the URL + local copy stay the whole story?
- Does sharing need a redacted view (e.g. hide chosen years or cells)?
- Should local edits also be kept in browser storage so a lost link doesn't lose the grid?

## Interview
- Scripted or conversational: decide after seeing both mockups.
- Tone: quick-fire (one cell per question) or conversational (one answer may fill several cells)?
- How many questions per session before it gets tiring?

## Data sources
- Which source first? Photo metadata is the richest and can stay fully local.
- World events: which dataset, and how many per month is useful rather than noisy?

## Display
- Which alternate view matters most after the grid: timeline, or parallel timeline?
- Parallel with what first: world events, or another person's grid?
